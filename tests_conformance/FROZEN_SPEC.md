`tests_conformance/`. It was supplied directly by the project owner as the
spec for an independent conformance/acceptance test suite, and is
reproduced here **verbatim, unedited** so that every test can cite a
specific section (e.g. "per FROZEN_SPEC.md section J4") without the spec
drifting out of sync with what the tests actually check.

disagrees with this file, the test should fail and the disagreement should
